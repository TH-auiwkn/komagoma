1. 数学の基礎 step1 - 微分から単回帰へ

学習の流れ: 本講座で登場する関数と記号 → 微分とは → 微分の公式 → 合成関数の微分 → 偏微分 → 単回帰分析の問題設定と数理モデル → 目的関数 → 最適なパラメータを求める → Pythonで実装1

1-1 本講座で登場する関数と記号

総和 Σ は多数のデータを一括して表し、総乗 Π は積を一括表記する。指数関数 exp(x)=e^x と対数 log(x) は逆関数で、log(xy)=log x+log y が重要。極限 lim は、変数をある値へ近づけたときの関数値を扱い、微分の土台になる。

キー式・実装: \(\displaystyle \sum_{n=1}^{N}x_n\), \(\exp(x)=e^x\), \(\log(xy)=\log x+\log y\)

1-2 微分とは

微分は関数の『瞬間的な変化率』、幾何学的には接線の傾き。差分 (f(x+h)-f(x))/h で平均変化率を作り、h→0 の極限を取る。機械学習では、損失がどちらへどれだけ変化するかを知る道具になる。

キー式・実装: \(\displaystyle f'(x)=\lim_{h\to0}\frac{f(x+h)-f(x)}{h}\)

1-3 微分の公式

定数、べき乗、和・差、定数倍、積、商の微分を整理する。特に (x^n)'=n x^(n-1)、(e^x)'=e^x、(log x)'=1/x は頻出。式を展開してから微分する方法と、公式を直接使う方法を使い分ける。

キー式・実装: \( (x^n)'=nx^{n-1},\quad (e^x)'=e^x,\quad (\log x)'=\frac1x \)

1-4 合成関数の微分

関数の中に別の関数が入るときは連鎖律を使う。外側の微分と内側の微分を掛ける考え方で、ニューラルネットワークの逆伝播そのものにつながる。計算グラフを『局所微分の積』として追うと理解しやすい。

キー式・実装: \(\displaystyle \frac{dy}{dx}=\frac{dy}{du}\frac{du}{dx}\)

1-5 偏微分

複数変数関数で、一つの変数だけを動かし他を固定して微分する。∂f/∂x は x 方向の変化率。パラメータが多数ある機械学習では、各パラメータについて偏微分し、損失を下げる方向を求める。

キー式・実装: \(f(x,y)=x^2+xy\Rightarrow \frac{\partial f}{\partial x}=2x+y,\ \frac{\partial f}{\partial y}=x\)

1-6 単回帰分析の問題設定と数理モデル

一つの説明変数 x から目的変数 y を直線で予測する。モデルは ŷ=wx+b（講座の記号に応じて a,b とも表す）。w は傾き、b は切片。観測値と予測値のずれを小さくする w,b をデータから学習する。

キー式・実装: \(\hat y_n=wx_n+b\)

1-7 目的関数

モデルの良し悪しを一つの値で測る。回帰では残差 y-ŷ の符号が打ち消し合わないよう二乗し、全サンプルで平均する平均二乗誤差を使う。目的関数を明示することで『学習』が最小化問題になる。

キー式・実装: \(\displaystyle \mathrm{MSE}=\frac1N\sum_{n=1}^{N}(y_n-\hat y_n)^2\)

1-8 最適なパラメータを求める

目的関数を w,b で偏微分し、勾配が 0 となる点を解析的に求めるか、勾配降下法で反復的に近づく。更新方向は勾配の反対。学習率 η が大きすぎると発散し、小さすぎると収束が遅い。

キー式・実装: \(\displaystyle \theta\leftarrow\theta-\eta\frac{\partial L}{\partial\theta}\)

1-9 Pythonで実装1

NumPy 配列で x,y を準備し、予測、損失、勾配、更新を順に実装する。shape を確認し、途中値を可視化・出力して数式とコードの対応を保つ。scikit-learn の結果とも比較すると検算になる。

キー式・実装: \(\mathrm{predict}\to\mathrm{loss}\to\mathrm{gradient}\to\mathrm{update}\)

  • □ MSEを選ぶ理由と勾配降下法の更新方向を説明できる

2. 数学の基礎 step2 - 線形代数から重回帰へ

学習の流れ: 線形代数が必要な理由 → スカラ・ベクトル・行列・テンソル → 主要な演算 → 単位行列と逆行列 → 線形結合と二次形式 → ベクトルによる微分と勾配 → ベクトル関連の関数 → 重回帰分析 → 目的関数 → 最適なパラメータを求める → Pythonで実践2

2-1 線形代数が必要な理由

多サンプル・多特徴量を一度に扱うため、スカラーの式をベクトル・行列でまとめる。行列積は多数の加重和を並列に計算する表現であり、重回帰やニューラルネットワークの中心操作になる。

キー式・実装: \(\hat{\mathbf y}=X\mathbf w+\mathbf b\)

2-2 スカラ・ベクトル・行列・テンソル

0階のスカラー、1階のベクトル、2階の行列、3階以上のテンソルを区別する。重要なのは shape（軸ごとの要素数）。サンプル軸、特徴量軸、バッチ軸を意識すると実装ミスが減る。

キー式・実装: \(X\in\mathbb{R}^{N\times D},\ \mathbf w\in\mathbb{R}^{D},\ \mathbf y\in\mathbb{R}^{N}\)

2-3 主要な演算

要素ごとの加減乗除と行列積を区別する。内積は対応要素の積の総和、行列積は行と列の内積。転置で行列の向きを入れ替える。積 AB が定義できるのは A の列数と B の行数が一致するとき。

キー式・実装: \(\mathbf a^\top\mathbf b=\sum_i a_ib_i,\quad (AB)_{ij}=\sum_k A_{ik}B_{kj}\)

2-4 単位行列と逆行列

単位行列 I は掛けても値を変えない。逆行列 A⁻¹ は AA⁻¹=I を満たし、連立方程式の形式解に使える。ただし逆行列が存在しない場合や数値的に不安定な場合があり、実装では solve や疑似逆行列を使うことが多い。

キー式・実装: \(A\mathbf x=\mathbf b\Rightarrow\mathbf x=A^{-1}\mathbf b\)

2-5 線形結合と二次形式

線形結合はベクトルを重み付きで足す操作で、線形モデルの予測に直結する。二次形式 xᵀAx は二乗誤差や曲率の表現に現れる。ベクトル表記にすると多数の式を短く扱える。

キー式・実装: \(w_1x_1+\cdots+w_Dx_D=\mathbf w^\top\mathbf x,\quad \mathbf x^\top A\mathbf x\)

2-6 ベクトルによる微分と勾配

スカラー関数をベクトルで微分すると、各成分の偏微分を並べた勾配ベクトルになる。勾配は関数が最も急に増える方向を示すため、負の勾配方向へ進めば目的関数を下げられる。

キー式・実装: \(\displaystyle \nabla f=\left[\frac{\partial f}{\partial x_1},\ldots,\frac{\partial f}{\partial x_D}\right]^\top\)

2-7 ベクトル関連の関数

内積、ノルム、平均、和などをベクトル表記で扱う。L2ノルム ||x||₂ は長さ、二乗ノルム ||x||₂² は二乗和。距離や正則化、損失関数の理解に使う。

キー式・実装: \(\|\mathbf x\|_2=\sqrt{\sum_i x_i^2},\quad \|\mathbf y-X\mathbf w\|_2^2\)

2-8 重回帰分析

複数特徴量を用い、各特徴量の重みを学習する。バイアスを含めるには X に1の列を追加する表現も可能。特徴量の尺度が大きく違うと最適化しにくいため標準化が有効。

キー式・実装: \(\hat{\mathbf y}=X\mathbf w\quad\text{（切片列を含む場合）}\)

2-9 目的関数

残差ベクトル r=y-Xw を使うと二乗誤差は rᵀr で表せる。スカラー式とベクトル式が同じ内容であることを確認する。正規化係数 1/N や 1/2N は勾配の定数を整えるために選ばれる。

キー式・実装: \(\displaystyle L(\mathbf w)=\frac1N\|\mathbf y-X\mathbf w\|_2^2\)

2-10 最適なパラメータを求める

損失を w で微分し 0 と置くと正規方程式が得られる。解析解は一度で求まるが、特徴量が多い場合や逆行列が不安定な場合は反復最適化を使う。

キー式・実装: \(\mathbf w=(X^\top X)^{-1}X^\top\mathbf y\)

2-11 Pythonで実践2

二次元配列 X とベクトル w の shape を確認し、@ または np.dot で行列積を計算する。np.linalg.solve / pinv、あるいは勾配降下法を用い、予測値・損失・係数を検証する。

キー式・実装: \(\mathrm{shape}(X)=(N,D),\quad \mathrm{shape}(\mathbf w)=(D,)\)
章末チェック
  • □ 要素積と行列積の違いをshapeで判断できる
  • □ 重回帰の予測・損失・勾配をベクトル表記でつなげられる

3. 数学の基礎 step3 - 確率・情報理論から分類へ

学習の流れ: 基本統計量 → 確率変数と確率分布 → 期待値 → 正規化 → 情報理論 → 交差エントロピー → ロジスティック回帰の数理モデル → パラメータの最適化 → Pythonで実装3

3-1 基本統計量

平均は中心、分散・標準偏差はばらつきを表す。共分散は2変数が同方向に変化する傾向、相関係数は尺度を除いた関係の強さ。外れ値や分布形状も合わせて見る。

キー式・実装: \(\displaystyle \mu=\frac1N\sum_nx_n,\quad \sigma^2=\frac1N\sum_n(x_n-\mu)^2\)

3-2 確率変数と確率分布

結果に数値を割り当てる確率変数と、その値ごとの確率を表す分布を学ぶ。離散分布では確率の総和、連続分布では密度の積分が1。分類モデルの出力はクラス確率として解釈される。

キー式・実装: \(P(X=x)\ge0,\quad \sum_xP(X=x)=1\)

3-3 期待値

確率で重み付けした平均。関数 g(X) の期待値も各値に対して g(x)P(x) を足す。機械学習の損失は、未知のデータ分布に対する期待損失を訓練データの平均で近似する。

キー式・実装: \(\displaystyle \mathbb E[X]=\sum_x xP(X=x)\)

3-4 正規化

値を扱いやすい尺度へ変換する。min-max正規化は範囲を揃え、標準化は平均0・標準偏差1にする。確率としての正規化では非負値を総和で割り、合計1にする。

キー式・実装: \(z=\frac{x-\mu}{\sigma},\quad p_i=\frac{a_i}{\sum_j a_j}\)

3-5 情報理論

自己情報量 -log p は、起こりにくい事象ほど情報が大きいことを表す。エントロピーは自己情報量の期待値で、分布の不確実性を測る。対数により独立事象の確率の積が情報量の和になる。

キー式・実装: \(I(x)=-\log p(x),\quad H(p)=-\sum_i p_i\log p_i\)

3-6 交差エントロピー

真の分布 p と予測分布 q のずれを測る。one-hot教師では正解クラスの -log q だけが残る。正解確率が1に近いほど損失は小さく、0に近いほど急増する。

キー式・実装: \(H(p,q)=-\sum_i p_i\log q_i\)

3-7 ロジスティック回帰の数理モデル

線形結合 z=wᵀx+b をシグモイド関数で0〜1へ写し、二値クラスの確率を表す。決定境界は z=0（確率0.5）。名前は回帰だが用途は分類。

キー式・実装: \(\displaystyle p(y=1\mid\mathbf x)=\sigma(z)=\frac{1}{1+e^{-z}}\)

3-8 パラメータの最適化

交差エントロピーを目的関数にし、w,b の勾配を求めて更新する。シグモイドと交差エントロピーを組み合わせると勾配が予測確率と正解の差に整理され、学習しやすい。

キー式・実装: \(\displaystyle \frac{\partial L}{\partial z}=p-y,\quad \mathbf w\leftarrow\mathbf w-\eta\nabla L\)

3-9 Pythonで実装3

logits→sigmoid→binary cross entropy→勾配更新の流れを実装する。log(0)を避けるクリップ、訓練/検証分割、accuracyだけでなく混同行列や適合率・再現率の確認も重要。

キー式・実装: \(p\ge0.5\Rightarrow\hat y=1\quad\text{（閾値は目的に応じて調整）}\)
章末チェック
  • □ エントロピーと交差エントロピーの役割を区別できる
  • □ logits、sigmoid、確率、閾値の関係を説明できる

4. ニューラルネットワーク 数学編

学習の流れ: ニューラルネットワークの構造 → 順伝播：線形変換 → 順伝播：非線形変換 → 順伝播：目的関数 → 逆伝播：パラメータの更新

4-1 ニューラルネットワークの構造

入力層、隠れ層、出力層からなり、各層は線形変換と非線形変換を重ねる。重み W とバイアス b が学習対象。複数層にすることで単純な直線では表せない関係を近似できる。

キー式・実装: \(\mathbf z^{(l)}=W^{(l)}\mathbf x^{(l-1)}+\mathbf b^{(l)},\quad \mathbf x^{(l)}=\phi(\mathbf z^{(l)})\)

4-2 順伝播：線形変換

前の層の出力に重み行列を掛け、バイアスを足す。バッチをまとめる場合は行列の shape を揃える。各ニューロンは入力の線形結合を計算している。

キー式・実装: \(Z=XW+\mathbf b\quad\text{（バッチを行に並べる流儀）}\)

4-3 順伝播：非線形変換

活性化関数がなければ多層の線形変換も一つの線形変換に縮退する。ReLU は正の部分を通し、sigmoid は0〜1、softmax は多クラス確率を作る。出力層は課題に合う関数を選ぶ。

キー式・実装: \(\mathrm{ReLU}(z)=\max(0,z),\quad \mathrm{softmax}(z_i)=\frac{e^{z_i}}{\sum_j e^{z_j}}\)

4-4 順伝播：目的関数

回帰ならMSE、二値分類なら二値交差エントロピー、多クラス分類ならsoftmax交差エントロピーが基本。ミニバッチ内で平均し、正則化を加える場合もある。

キー式・実装: \(\displaystyle L=-\frac1N\sum_n\sum_k y_{nk}\log p_{nk}\)

4-5 逆伝播：パラメータの更新

出力側から連鎖律を逆向きに適用し、各層の重み・バイアスの勾配を効率的に計算する。勾配をoptimizerへ渡して更新する。計算グラフ上で『上流勾配×局所微分』を繰り返す。

キー式・実装: \(\delta^{(l)}=\left(\delta^{(l+1)}(W^{(l+1)})^\top\right)\odot\phi'(\mathbf z^{(l)})\)
章末チェック
  • □ 各層の線形変換と活性化関数の役割を説明できる
  • □ 逆伝播を連鎖律として説明できる

5. ニューラルネットワーク 実装編

学習の流れ: PyTorchとエコシステム → ネットワークの定義と順伝播の計算 → データセットの準備 → ネットワークの訓練 → PyTorch Lightningによる簡略化 → Optunaによるハイパーパラメータ最適化

5-1 PyTorchとエコシステム

Tensor はGPU計算と自動微分に対応する多次元配列。torch.nn は層・損失、torch.optim は最適化、Dataset/DataLoader はデータ供給を担う。device と dtype を揃える。

キー式・実装: \(\texttt{requires\_grad=True}\Rightarrow\texttt{backward()}\)

5-2 ネットワークの定義と順伝播の計算

nn.Module を継承し、__init__で層を定義、forwardでデータの流れを書く。nn.Linear と活性化関数を組み合わせる。入力・出力次元を明示し、ダミー入力でshapeを確認する。

キー式・実装: \(\texttt{model(x)}\to\texttt{forward},\quad \texttt{model.parameters()}=\text{学習対象}\)

5-3 データセットの準備

特徴量とラベルをTensor化し、DatasetとDataLoaderでミニバッチを生成する。shuffleは訓練時に有効。訓練・検証・テストを分離し、前処理は訓練データでfitして他へ適用する。

キー式・実装: \(\texttt{for\ x\_batch,\ y\_batch\ in\ train\_loader:}\)

5-4 ネットワークの訓練

典型的な1ステップは zero_grad→forward→loss→backward→step。訓練時はmodel.train()、評価時はmodel.eval()とtorch.no_grad()を使う。epochごとに訓練・検証損失を記録して過学習を監視する。

キー式・実装: \(\texttt{zero\_grad()}\to\texttt{loss.backward()}\to\texttt{optimizer.step()}\)

5-5 PyTorch Lightningによる簡略化

LightningModuleにmodel、training_step、validation_step、configure_optimizersを整理し、Trainerが学習ループ、device、ログ、チェックポイントを管理する。定型処理を減らし再現性を高める。

キー式・実装: \(\texttt{Trainer.fit(model, train\_loader, val\_loader)}\)

5-6 Optunaによるハイパーパラメータ最適化

trial.suggest_*で学習率、層数、ユニット数などの探索空間を定義し、objectiveが検証指標を返す。study.optimizeで複数trialを実行する。テストデータを探索に使わず、計算予算と再現性を管理する。

キー式・実装: \(\texttt{best\_params=study.best\_trial.params}\)
章末チェック
  • □ PyTorchの標準訓練ループを順番通り書ける
  • □ 検証データとテストデータの役割を分けて説明できる

最重要の対応表

数学上の概念機械学習での意味PyTorchでの対応
合成関数の微分逆伝播autograd / loss.backward()
勾配損失を最も増やす方向parameter.grad
負の勾配方向損失を下げる更新optimizer.step()
行列積層の線形変換nn.Linear / @
交差エントロピー分類の不一致度CrossEntropyLoss
期待値・平均データ分布上の損失近似batch lossのmean

実装時の落とし穴

  • Tensorのshape不一致 - バッチ軸と特徴量軸を毎回確認する。
  • logitsと確率の混同 - CrossEntropyLossには通常softmax後ではなくlogitsを渡す。
  • 勾配の蓄積 - 各ステップでoptimizer.zero_grad()を行う。
  • 評価時の挙動 - model.eval()とtorch.no_grad()を使う。
  • データ漏洩 - 標準化の統計量やハイパーパラメータ選定にテストデータを使わない。
  • 指標の偏り - 不均衡分類ではaccuracyだけで判断しない。
